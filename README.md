# 📚 LibraFlow

> A modern AI-powered Library Management System built with the MERN stack.
> 
LibraFlow is a full-stack library management platform designed to simplify book discovery, borrowing, authentication, and library operations.

It also includes an **AI-powered library chatbot** that allows users to search for books using natural language, check availability, ask questions about books, and maintain context across conversations.

---

## ✨ Features

### 🔐 Authentication

- User registration and login
- Secure password hashing using bcrypt
- JWT-based authentication
- HTTP-only cookie support
- Bearer token authentication
- Email verification
- Protected routes
- Logout functionality
- Current-user endpoint
- Role-based user support

### 📚 Book Management

- Add books to the library
- Search books
- View book details
- Categorize books
- Track available copies
- Track book location
- Store ISBN, author, publisher, language, description, and publication year

### 📖 Borrowing System

- Borrow books
- Track available copies
- Return books
- Manage borrowing records
- Prevent borrowing when copies are unavailable

### 🤖 AI Library Chatbot

LibraFlow includes an AI-powered chatbot that can understand natural-language queries.
